Kalibrasi 2-Titik Sensor pH (pH 4.01 & pH 6.86)

Celupkan probe pH ke dalam larutan buffer pH 4.01 & 6.86, lalu masukkan nilai tegangan ADC (Volt) yang terbaca pada serial monitor.

Rumus Terpasang: pH = -5.700 * V + 16.260
Kalibrasi Nutrisi (TDS / PPM Factor)

Atur faktor konversi tegangan sensor TDS ke konsentrasi PPM nutrisi larutan baku AB Mix.

Faktor Konversi PPM: Factor = 0.50 (EC = PPM / 500)

#include <PubSubClient.h>
#include <ArduinoJson.h>

const char* WIFI_PASS = "PASSWORD_WIFI_ANDA";
const char* MQTT_BROKER = "broker.hivemq.com";
const int MQTT_PORT = 1883;
